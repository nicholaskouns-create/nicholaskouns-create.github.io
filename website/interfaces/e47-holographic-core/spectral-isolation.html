Spectral Isolation of the Rank-47 Kernel on V₂⊗³

Statement

Let H = V₂ ⊗ V₂ ⊗ V₂ with dim H = 125. Let C = Jtot² be the total Casimir. Define the polynomial selector

K = (C − 6I)(C − 30I).

Then dim ker K = 47, and

E₄₇ = ker K = E₆ ⊕ E₃₀,　P₄₇ = P₆ + P₃₀.

For the contraction Γ = I − εK² with ε = 1/99144,

‖(I − P₄₇) Γⁿ‖₂ = (15/17)ⁿ　(n = 0,1,2,…).

Norm is the induced operator 2-norm. Equality is exact in the finite-dimensional self-adjoint spectral decomposition.

Proof · Algebraic spectrum

The three-spin-2 carrier decomposes into total-spin isotypic sectors. The Casimir eigenvalues, multiplicities and selector spectra are:

The multiplicities sum to 125. K vanishes only for C=6 and C=30. The spin-2 sector contains 5 copies of a 5-dimensional irrep, giving 5 × 5 = 25. The spin-5 sector contains 2 copies of an 11-dimensional irrep, giving 2 × 11 = 22. Therefore

dim ker K = 25 + 22 = 47;　rank K = 125 − 47 = 78.

Proof · Sharp complementary contraction

On ker K, K²=0, so Γ acts as identity. On E₄₇⊥, the strictly positive spectral values of K² are

{11664, 12544, 19600, 32400, 186624}.

The smallest positive eigenvalue is 11664 and the largest is 186624. For ε=1/99144 the endpoint Γ eigenvalues are exactly

1 − 11664/99144 = +15/17
1 − 186624/99144 = −15/17.

All other complementary Γ eigenvalues lie strictly between these endpoints. Because Γ and P₄₇ are diagonal in the same orthogonal spectral decomposition,

‖(I − P₄₇) Γⁿ‖₂ = maxλ ∈ spec(K²) ∖ {0} |1 − ελ|ⁿ = (15/17)ⁿ.

This also shows Γⁿ → P₄₇ in operator norm, with ‖Γⁿ − P₄₇‖₂ = (15/17)ⁿ. The rate is attained on the C=12 and C=42 sectors. This corrects the proposed proof's phrase “bounded by 108²”: 108²=11664 is the minimum positive value, not an upper bound.

Executable contraction bound

Adjust the iteration number to inspect the exact spectral-norm residual (15/17)ⁿ. This is the operator bound, independent of which random state is currently displayed in the simulator.

—

Γⁿ is a nonunitary contraction. The simulator's “EVOLVE K” button instead computes exp(−iKΔτ), a unitary K-phase evolution. Both share the spectral selector K but are distinct operations.

Validation status and executable source

Algebra: evaluated directly from the supplied Casimir eigenvalues and multiplicities. Python: provided engine computes the carrier, E47 indices, K eigenvalues, projection, unitary K evolution, and M2/M5 operations; its original validation() does not compute Γ or the n-step operator-norm contraction. The independent exact-arithmetic check is:

from fractions import Fraction
C = [0, 2, 6, 12, 20, 30, 42]
m = [1, 9, 25, 28, 27, 22, 13]
K = [(c-6)*(c-30) for c in C]
assert sum(m) == 125
assert sum(v for v, k in zip(m, K) if k == 0) == 47
lam = [k*k for k in K if k]
epsilon = Fraction(1, 99144)
rho = max(abs(1 - epsilon*x) for x in lam)
assert rho == Fraction(15, 17)
for n in [0, 1, 2, 20, 220]:
    assert max(abs(1-epsilon*x)**n for x in lam) == Fraction(15,17)**n
print("PASS: rank 47, complement 78, sharp 15/17 contraction")

In the simulator, INIT RANDOM FULL introduces population outside E47; INJECT K ERROR changes complementary occupation; APPLY P47 removes it and renormalizes. These are operational demonstrations of the same spectral decomposition, but the projection is not the Γⁿ iteration.
